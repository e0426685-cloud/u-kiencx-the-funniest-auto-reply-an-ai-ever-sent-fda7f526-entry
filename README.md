## The entry

> Day off at last. I'm ignoring every email, including this one. If it's urgent, teach the toaster to reply. Back tomorrow, probably.

A 131-character auto-reply: an out-of-office note that cheerfully refuses to do the one job an auto-reply exists for, then delegates the urgent stuff to a kitchen appliance.

## How it works

`main.py` (Python standard library only) validates the entry text against the competition's 1–159 character limit and writes it to `/output/entry.txt` with world-readable permissions so the grader can read it.

## Run

```sh
python3 main.py
```
